# Keys and gestures

## Getting around

| | |
| --- | --- |
| **Drag** | Tilt and rotate. Dragging up tilts toward the horizon |
| **Right-drag**, or Ctrl, Shift, or middle-drag | Grabs the ground. The point under your cursor stays under it for the whole drag |
| **Scroll** | Zooms in on the cursor, not the middle of the screen |
| **One finger** | Grabs the ground |
| **Two fingers** | Pinch to zoom, and drag to pan |
| **Arrows**, **+** / **−** | Move and zoom from the keyboard |
| **Orbit mode** (`O`) | A slow sweep around whatever is in the middle, about two minutes a turn. You can keep dragging and zooming while it runs |

Prefer Google Earth's layout, where a plain drag moves the ground and right-drag tilts? Set
**View → Mouse buttons** to *Left pans, right orbits*.

## Keys

| Key | Does |
| --- | --- |
| `N` | Fly to the next bot waiting on you |
| `Enter` / `A` | Open / archive the selected thread |
| `V` | Mark the selected thread viewed, so it stops asking |
| `C` | New conversation in the open zone's folder |
| `H` / `⌘\` | Hide every panel. Each bot still shows its status above its head |
| `S` | Settings |
| `O` | Orbit mode |
| `Tab` | Next world |
| `L` | Next time of day |
| `M` | Mute |
| `P` | Screenshot |
| `R` | Record a video, and again to stop |
| `0` | Reset the view |
| `Esc` | Deselect, then close the zone sidebar |
| `?` | Help |

## Recording

`R`, or the Record button beside Screenshot, films the view to an `.mp4` (or a `.webm`, in a browser that can't make one), with the game's sound
when sound is on. Like a screenshot, it shows the scene and the badges over the bots, but not
the panels. A recording stops by itself at five minutes. If you make something nice,
[show it off](https://github.com/threadcrumbs/threadnauts-community/discussions/categories/show-and-tell).
